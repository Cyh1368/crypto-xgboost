<DESCRIPTION>
The model was suffering from "prediction collapse," where it predicted values too close to the mean, resulting in a very low `pred_std_ratio` (0.0193 vs target 0.15). This was caused by excessive regularization and insufficient model expressivity. 

The fix involves:
1. Increasing `learning_rate` (0.04 -> 0.12) and `max_depth` (6 -> 7) to allow the model to capture more complex patterns.
2. Significantly reducing regularization (`reg_lambda` 1.5 -> 0.05, `reg_alpha` 0.05 -> 0.0) and `min_child_weight` (1) to encourage the model to make more confident predictions.
3. Expanding the feature set to include more granular lags, momentum indicators, and volatility-adjusted returns (Sharpe-like features) to provide stronger signals.
4. Adding interaction features (e.g., return * volatility) to help the model identify regime-dependent signals.
5. Ensuring the feature count stays under the 80-feature limit while maximizing predictive power.
