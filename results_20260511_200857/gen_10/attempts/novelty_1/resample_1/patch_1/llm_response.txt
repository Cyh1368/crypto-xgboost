The previous model failed due to a "collapsed" prediction spread (`pred_std_ratio=0.0091`), which triggered a severe penalty. This happens when the model is underfitting or too heavily regularized in a noisy environment, leading it to predict values close to the mean (0).

To fix this, I have:
1.  **Increased Model Expressivity:** Boosted `max_depth` (4 → 6) and `learning_rate` (0.01 → 0.05).
2.  **Reduced Regularization:** Lowered `min_child_weight` (10 → 1) to allow the model to capture smaller, more granular signals, and reduced `reg_alpha` and `reg_lambda`.
3.  **Enhanced Feature Engineering:**
    *   Added scale-invariant momentum features (EMA distances, log-returns of multiple lags).
    *   Added standard indicators like Bollinger Band % and VWAP deviation.
    *   Modified volume features to use log-transforms for better distribution.
    *   Improved the OBI (Orderbook Imbalance) calculation with a more efficient and robust vectorized-style implementation.
    *   Added regime-specific indicators like volatility-normalized returns and MA-trend crossovers.
4.  **Ensured Feature Robustness:** Used `ffill()` and `dropna()` to handle rolling window warm-ups without yielding NaNs to the XGBoost model.
