**Core Strategy: Cross-sectional Rank Features**

Following the recommendation, I'm implementing percentile-based ranking of key features within rolling windows. This creates truly distribution-invariant signals that should remain stable across regime shifts:

1. **ret_3_rank_40**: Ranks 3-bar returns within 40-bar window. A 1% move in low-vol is equivalent to a 3% move in high-vol when both are at 80th percentile.

2. **efficiency_10_rank_60**: Ranks market efficiency (directional move / total path length) within 60-bar window. Captures relative trending vs mean-reverting character independent of absolute volatility.

3. **rsi_14_rank_40**: Already present but underweighted. Ranking RSI itself makes overbought/oversold levels regime-relative rather than absolute.

4. **vol_rank_60**: Extended from vol_rank_40 to capture longer-term volatility percentile, making volatility regime features more stable.

**Additional Improvements:**

- Reduced feature count from ~95 to ~80 by removing redundant absolute-value features that failed in prior generations
- Kept successful z-scored features (ret_z_8, ret_z_13, ret_z_21) which already provide some normalization
- Maintained interaction terms (mom_x_volreg, momentum_vol_interaction) as they combine normalized signals
- Slightly reduced regularization (lambda 1.25→1.15, alpha 0.10→0.08) to allow model to use these more stable features
- Increased min_child_weight (4→5) to force higher-sample patterns that generalize better

This approach directly addresses the regime shift problem: when val period volatility or trend character differs from train, ranked features maintain their predictive power because they measure relative position in the current distribution rather than absolute levels.
