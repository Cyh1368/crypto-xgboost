<DESCRIPTION>
This edit targets the core failure mode: the model is still learning patterns that vanish in the newest regime, so the validation slope collapses despite acceptable directional accuracy.

I’m proposing two coordinated changes:

1. Feature engineering:
   - add longer-window rolling z-scores for returns to make the signal more regime-invariant
   - add explicit regime-shift features that measure divergence between short-, medium-, and longer-horizon normalized return behavior
   - add short-horizon volatility/efficiency trend features to capture changes in market character rather than just absolute levels
   - remove low-value time-of-day Fourier features to keep the feature count under the 80 limit and reduce regime-specific leakage

2. Hyperparameters:
   - slightly increase model expressivity with a modestly deeper tree and lower child weight
   - reduce regularization a bit so the model can use the new regime-shift features
   - keep estimator count and learning rate conservative enough to avoid exploding overfit

The goal is to lift validation slope and prediction spread while preserving the current directional edge.
</DESCRIPTION>
