<DESCRIPTION>
This edit targets the core failure mode: the model’s signal survives training but decays sharply in the later regime. I’m making two coordinated changes.

1. Feature engineering:
   - Replace the long, regime-specific emphasis with shorter-horizon, regime-normalized signals.
   - Add rolling z-scores for volatility, price deviation, volume, and key interaction terms so the model sees relative state instead of raw magnitude.
   - Add explicit “market character change” features such as volatility trend, autocorrelation trend, and efficiency trend.
   - Add a compact momentum × volatility regime interaction and a few short lookback regime features that should transfer better to the most recent period.

2. Hyperparameters:
   - Slightly increase expressivity by raising learning rate and reducing overly strong regularization.
   - Keep tree count moderate and early stopping fairly tight so the model can learn stronger slopes without drifting into the overfit patterns seen in earlier attempts.
   - This should help lift `pred_std_ratio` and `val_slope` while keeping generalization loss controlled.

The combined intent is to preserve the current good DA while reducing slope collapse across the second regime shift.
