<DESCRIPTION>
This edit targets the main failure mode: the model’s slope collapses on the validation regime because the current feature set still encodes too many absolute levels and too little normalized, regime-relative structure.

I propose two coordinated changes:

1. **Hyperparameter adjustment for stronger but still controlled expressivity**
   - Slightly raise `learning_rate` and reduce `n_estimators` / `early_stopping_rounds` proportionally.
   - Lower `min_child_weight` and regularization a bit so the trees can actually use the new normalized features.
   - Keep depth moderate to avoid overfitting.

2. **Add short-window rolling z-score / trend features and interaction terms**
   - Normalize momentum, volatility, ATR, volume, and efficiency by recent rolling statistics.
   - Add trend-of-character features such as `vol_trend_5_10`, `eff_trend_5_10`, `autocorr_trend_5_10`.
   - Add `momentum × volatility regime` interaction using the shorter horizon vol estimate.
   - These are designed to be more regime-invariant and to preserve slope in the validation period.

This should help increase `val_slope` and `pred_std_ratio` without materially increasing feature count or runtime, while keeping the model from relying too heavily on absolute price-regime levels that vanish after the train/test split.
</DESCRIPTION>
