# Analysis of Program Evaluation Results

## Successful Algorithmic Patterns

- **Moderate regularization with balanced model capacity**: The current best program (Generation 18, score=-1.55) achieves the highest performance using XGBoost with 560 estimators, max_depth=4, reg_lambda=1.8, and learning_rate=0.055. This configuration avoids the over-regularization trap that plagued most other programs while maintaining sufficient complexity to capture signal. Programs with heavier regularization (e.g., Generation 6 with reg_lambda=8.0, score=-1.74; Generation 17 with reg_lambda=3.0, score=-2.17) consistently showed worse prediction collapse.

- **Comprehensive multi-scale feature engineering with 80+ features**: The best program successfully implements extensive feature sets including short-horizon returns (1-20 lags), rolling z-scores across multiple windows (10, 20, 40), volatility trends, efficiency metrics, RSI variants, moving average structures, Bollinger bands, ATR normalization, MACD signals, volume interactions, and momentum-volatility interactions. This approach outperforms simpler feature sets, achieving 19.9% slope ratio compared to single-digit percentages in most other programs.

- **Rolling z-score normalization for regime adaptation**: The best program applies z-score normalization across 10, 20, and 40-bar windows (`ret_z_10`, `ret_z_20`, `ret_z_40`), which helps achieve better generalization (96.0% generalization_ratio) compared to programs without this normalization. Generation 5 (score=-3.00) and Generation 12 (score=-2.15) also attempted rolling z-scores but with heavier regularization that suppressed the benefits.

- **Balanced early stopping configuration**: The best program uses 55 early stopping rounds with learning_rate=0.055, allowing sufficient training iterations (560 estimators) without overfitting. This contrasts with programs using shorter early stopping (e.g., Generation 7 with 35 rounds, score=-2.66; Generation 11 with 35 rounds, score=-3.79) that may have stopped training prematurely.

## Ineffective Approaches

- **Excessive regularization consistently causes prediction collapse**: Programs with high regularization parameters show severe performance degradation. Generation 6 (reg_lambda=8.0, min_child_weight=10, score=-1.74) achieved only 20.7% slope ratio with pred_std_ratio=0.05. Generation 17 (reg_lambda=3.0, score=-2.17) showed 14.4% slope ratio. Generation 9 (reg_alpha=0.25, reg_lambda=1.8, min_child_weight=6, score=-2.14) achieved only 9.8% slope ratio. All these programs received explicit warnings about prediction collapse toward the mean.

- **Shallow trees with conservative learning rates fail to capture signal**: Programs using max_depth=3 consistently underperform. Generation 7 (depth=3, lr=0.08, score=-2.66) achieved only 9% slope ratio. Generation 10 (depth=3, lr=0.08, score=-5.16) reached -2.0% slope ratio. Generation 11 (depth=3, lr=0.06, score=-3.79) showed 5.7% slope ratio. Generation 12 (depth=3, lr=0.06, score=-2.15) achieved 9.5% slope ratio. The combination of shallow trees and low learning rates appears insufficient for the feature complexity.

- **Implementation bugs and missing variable definitions**: Generation 1 (score=-10.00) crashed with KeyError: 'vol_regime' due to referencing an undefined variable while only defining 'vol_regime_fast'. This demonstrates that even promising architectural changes (z-score normalization, shorter lookbacks) fail completely when implementation is incorrect.

- **Extremely high tree counts without proportional benefit**: Generation 21 (640 estimators, score=-2.12) and Generation 8 (650 estimators, score=-2.23) show that simply increasing tree count beyond ~400-600 without adjusting other hyperparameters doesn't improve performance and may even worsen it due to overfitting or computational constraints affecting feature quality.

## Implementation Insights

- **Feature count management at 80-feature threshold**: The best program explicitly limits features to 80 (`if feat.shape[1] > 80: feat = feat.iloc[:, :80]`), which appears optimal. Programs attempting 100+ features (Generation 9, Generation 12, Generation 22) all scored worse (≤-2.12), suggesting that feature quality matters more than quantity and that excessive features may introduce noise or computational issues.

- **Multi-window volatility regime features provide stability**: The best program implements volatility across multiple horizons (5, 10, 20, 40 periods) with trend calculations (`vol_trend_10_20`, `vol_trend_20_40`) and ranking (`vol_rank_60`). This multi-scale approach to volatility appears more effective than single-window implementations. The program also creates regime ratios (`vol_regime_20_40`) that capture relative volatility states rather than absolute values.

- **Interaction terms between momentum, volatility, and volume**: The best program creates sophisticated interactions: `momentum_vol_interaction = ret_3 * vol_20`, `momentum_regime = ret_3 / (vol_20 + eps)`, `volume_price_pressure = volume_ratio_20 * price_sma10_dev`, and `volume_bb_interaction = volume_ratio_20 * bb_pct_20`. These multiplicative features capture non-linear relationships that appear critical for performance, as programs without such interactions consistently scored worse.

- **Efficiency and autocorrelation metrics capture market microstructure**: The best program implements efficiency ratios measuring path efficiency (`efficiency_10`, `efficiency_20`, `eff_trend`) and autocorrelation features (`autocorr_5`, `autocorr_10`, `autocorr_trend`). These features, which measure how directly price moves toward targets and whether returns exhibit serial correlation, appear to provide unique signal not captured by standard technical indicators.

## Performance Analysis

- **The best program achieves 19.9% slope ratio, significantly outperforming most alternatives**: Generation 18 (score=-1.55) maintains val_slope=0.0026 vs train_slope=0.0131, achieving 19.9% slope ratio. This is substantially better than the typical 5-10% range seen in most programs (Generation 7: 9%, Generation 11: 5.7%, Generation 12: 9.5%, Generation 14: 0.8%, Generation 21: 7.8%, Generation 22: 6.8%).
