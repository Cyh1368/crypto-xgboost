<DESCRIPTION>
This edit targets the core failure mode: the model’s signal decays almost completely by validation, which strongly suggests the learned patterns are too regime-specific and too dependent on longer horizons. I’m shifting the feature set toward short-memory, regime-invariant, and regime-change descriptors.

Key ideas:
- Replace long lookbacks like 60/200 with shorter 5–20 bar windows where possible.
- Add rolling z-scores for returns, volatility, volume, and price position so the model learns relative state rather than absolute levels.
- Add “change in market character” features such as volatility trend, efficiency trend, autocorrelation trend, and dispersion trend.
- Keep the feature count comfortably under 80 and maintain only past data.
- Preserve existing orderbook/funding support, but encode them through shorter-window normalization too.

I’m also making a small hyperparameter adjustment to slightly increase model capacity while reducing over-regularization. This should help lift prediction variance and slope without pushing too hard into overfit.
