<DESCRIPTION>
This edit attacks the two dominant failure modes in the current model: prediction collapse and regime fragility.

1. Hyperparameters:
   - Increase learning rate modestly and reduce excessive L1/L2 + child weight regularization so trees can express more signal.
   - Keep depth shallow to avoid overfit, but raise subsampling slightly and reduce `min_child_weight` so the model can use more splits.
   - Lower `early_stopping_rounds` a bit to match the higher learning rate.
   - Slightly relax target clipping to preserve more tail information, which helps slope/variance.

2. Features:
   - Replace longer-horizon, regime-specific signals with shorter lookback versions where possible.
   - Add rolling z-score normalization for price, return, volume, and volatility so the model sees regime-invariant inputs.
   - Add explicit change-in-market-character features: volatility trend, autocorr trend, efficiency trend, dispersion trend.
   - Add a compact momentum × volatility-regime interaction, which often generalizes better than the raw components alone.
   - Keep feature count safely under 80 by pruning a few weaker long-horizon features.

These changes should improve val slope and pred_std_ratio while preserving the already decent DA. The goal is to make the model less “mean-collapsed” and less dependent on one regime.
</DESCRIPTION>
