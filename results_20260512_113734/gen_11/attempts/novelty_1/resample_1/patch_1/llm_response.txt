<DESCRIPTION>
This edit targets the main failure mode: the model’s slope collapses in the validation regime because the current feature set is dominated by absolute, long-horizon signals that do not survive regime shifts. I propose two coordinated changes:

1. Make the booster less prone to fitting brittle, high-variance patterns by reducing depth/estimators and adding modest regularization.
2. Rebuild features around short lookbacks, rolling z-scores, and change-of-regime signals. This emphasizes rate-of-change and normalized structure rather than absolute levels, which should improve cross-regime transfer and lift validation slope without inflating feature count.

The resulting feature set stays compact, uses only past data, and keeps all interactions causal.
