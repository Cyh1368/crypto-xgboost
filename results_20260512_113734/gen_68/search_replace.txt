<DESCRIPTION>
This edit targets the main failure mode: the model learns signals that vanish in the newest regime, causing slope collapse and prediction compression toward the mean.

I am making two coordinated changes:

1. **Feature engineering update**
   - Add short-window percentile-rank features for returns, volatility, efficiency, and RSI.
   - Add explicit **change-in-market-character** features such as `vol_trend_short`, `eff_trend_short`, and `autocorr_trend_short`.
   - Add a compact interaction feature: `mom_x_vol_regime_short = ret3_rank_40 * vol_regime_short`.
   - These features are more regime-invariant than raw levels and should help the model keep usable slope in the validation regime.
   - The added windows are intentionally short (5–40 bars) to reduce dependence on stale structure.

2. **Hyperparameter update**
   - Slightly increase model expressivity and reduce over-regularization.
   - The current model is too compressed (`pred_std_ratio` is only ~0.04), so I relax regularization a bit and reduce `min_child_weight`.
   - This should help the new regime-invariant features actually be used by the trees instead of being flattened out.

The changes stay within the feature limit and only use past data.
</DESCRIPTION>
