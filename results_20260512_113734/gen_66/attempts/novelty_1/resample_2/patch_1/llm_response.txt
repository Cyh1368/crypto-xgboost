<DESCRIPTION>
The current model is still over-regularized: train slope is present, but predictions collapse sharply toward the mean on val, and pred_std_ratio remains far below target. The safest next step is to keep the successful depth-4 structure while reducing shrinkage from both L1/L2 and the split penalty, and slightly relaxing node constraints so the model can express more persistent signal across the train→test→val regime shifts.

This edit:
- lowers `reg_alpha` and `reg_lambda` to reduce prediction collapse,
- lowers `min_child_weight` and `gamma` slightly to allow more useful splits,
- keeps the architecture conservative (`max_depth=4`) to avoid regressing into unstable overfit,
- trims `early_stopping_rounds` a bit so the larger model does not over-train.

No feature changes are needed here because the current feature set already improved generalization ratio substantially; the bottleneck is now underfitting / collapsed outputs.
</DESCRIPTION>
