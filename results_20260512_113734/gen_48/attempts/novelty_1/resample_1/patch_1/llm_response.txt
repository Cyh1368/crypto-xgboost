<DESCRIPTION>
This edit focuses on the main failure mode: the model still learns brittle, regime-specific relationships that vanish in validation. I’m tightening the tree ensemble to reduce train-overfit while adding explicitly regime-conditioned versions of the strongest short-horizon signals.

The feature changes do three things:
1. Add short lookback, rolling-z normalized variants of return and price-location features, which are more stable across volatility regimes.
2. Add regime-adaptive interactions that modulate momentum and efficiency by current volatility regime, making the same signal mean different things in high- vs low-vol markets.
3. Add rate-of-change features for regime character itself, so the model can react to shifts rather than absolute levels.

The hyperparameter changes reduce depth and model size a bit, and increase child weight / regularization, which should help preserve slope on validation by discouraging overly specific splits. I also slightly relax target clipping to keep more usable signal amplitude, since the current model is already collapsing toward the mean.

All changes stay within the feature-count limit and use only past data.
</DESCRIPTION>
