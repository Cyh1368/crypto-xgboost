<DESCRIPTION>
This edit targets the main failure mode: the model’s slope collapses badly in validation because it relies too much on absolute, regime-specific levels from longer lookbacks. I’m adding shorter-horizon, rolling-normalized features that are more regime-invariant, plus explicit “trend of regime” features so the model can detect when volatility and efficiency are changing rather than just whether they are high or low.

I also slightly retune XGBoost to reduce brittle memorization while keeping enough capacity to avoid the current near-mean prediction collapse. The new configuration uses a shallower tree, more trees with a lower learning rate, and modest regularization so the model can fit robust short-horizon patterns without overfitting to the train regime.

The changes stay within the feature budget and only use past data.
