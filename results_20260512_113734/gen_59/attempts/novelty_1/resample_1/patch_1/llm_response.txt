<DESCRIPTION>
This edit targets the core failure mode: the model’s slope collapses in the newest regime because it relies too much on absolute-state features and not enough on regime-invariant, short-memory signals.

The feature changes add:
- longer rolling return z-scores at 40/60/80 bars, which are more stable across volatility regimes than raw returns,
- explicit regime-shift deltas between short and long z-scores, so the model can detect when the market character is changing rather than only its current level,
- a short-horizon momentum × volatility-regime interaction that is easier to transfer across regimes than raw momentum alone.

To keep feature count bounded and reduce low-value periodicity noise, the time-of-day features are removed. This makes room for the new regime features while staying comfortably under the 80-feature limit.

The hyperparameter changes slightly increase expressivity while keeping regularization present:
- a bit more depth and trees,
- lower min_child_weight,
- slightly weaker regularization,
- slightly slower learning with more boosting rounds.

This is intended to recover slope without reverting to the very overfit, regime-specific behavior seen earlier.
</DESCRIPTION>
