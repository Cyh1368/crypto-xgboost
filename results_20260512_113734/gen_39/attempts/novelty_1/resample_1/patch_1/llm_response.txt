<DESCRIPTION>
This edit targets the current failure mode directly: the model is still too conservative and its slope collapses in the validation regime. I am making two coordinated changes.

1. Hyperparameters are loosened slightly so XGBoost can express stronger patterns without becoming overly deep or unstable:
- a bit more tree count
- slightly deeper trees
- lower min_child_weight
- less regularization
- slightly higher learning rate

This should help recover prediction amplitude, which is currently extremely compressed.

2. Feature engineering is shifted further toward regime-invariant, short-memory signals:
- add rolling percentile-rank features for momentum, RSI, efficiency, and volatility regime
- add a short-term volatility acceleration term
- add a regime-conditional momentum interaction using the rank-transformed volatility regime

These features are designed to survive the train→val regime shift better than raw level features, while staying within the feature limit and using only past data.
</DESCRIPTION>
