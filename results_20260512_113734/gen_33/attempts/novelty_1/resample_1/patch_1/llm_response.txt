<DESCRIPTION>
The current best program achieves 96.0% generalization ratio but suffers from a val_slope that's only 7.8% of train_slope. The key insight from the best performer is that it includes `vol_regime_rank` and `vol_regime_20_40` but doesn't use them to modulate other features adaptively.

I will implement regime-conditional versions of the top-performing features by creating multiplicative interactions between momentum, efficiency, and autocorrelation features with volatility regime indicators. This approach makes features explicitly adapt to market conditions rather than assuming static relationships.

Specifically, I will:
1. Create high-volatility versions of momentum features (ret_3, ret_5) by multiplying with (vol_regime_rank > 0.7)
2. Create low-volatility versions of efficiency and autocorrelation features by multiplying with (vol_regime_rank < 0.3)
3. Add regime-conditional RSI features that behave differently in different volatility environments
4. Create a volatility regime transition indicator to capture regime shifts

This should improve the slope ratio by making the model learn regime-specific patterns that generalize better across the train→test→val boundaries.
