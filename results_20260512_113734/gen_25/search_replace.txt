<DESCRIPTION>
This edit targets the exact failure mode shown by the metrics: the model still has decent train/test directional skill, but the learned slope collapses on validation, which strongly suggests the signal is not being expressed in a regime-robust way.

I’m proposing two coordinated changes:

1. **Make the model slightly less over-regularized**
   The current XGB setup is still too conservative for this task. A modest increase in tree depth and a reduction in `min_child_weight`, `reg_alpha`, and `reg_lambda` should help the model retain useful slope without exploding overfit. I also slightly lower the learning rate and raise estimators so the model can fit the more nuanced regime-conditional interactions.

2. **Add explicit regime-conditional versions of the strongest short-horizon features**
   The current feature set already has regime descriptors, but they are not strongly used to modulate the predictive features. To address the second regime shift, I’m adding gated interaction terms:
   - momentum under high/low volatility
   - efficiency under high/low volatility
   - autocorrelation under high/low volatility
   - a compact momentum × volatility-regime interaction using both a continuous rank and a binary gate

These features stay within the “past data only” constraint, remain under the 80-feature cap, and directly encode the idea that the same market pattern can mean different things in different volatility regimes. That should help preserve slope into validation while also giving the model more expressive power, which should improve `pred_std_ratio` and reduce mean-collapse.
</DESCRIPTION>
