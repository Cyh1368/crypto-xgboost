<DESCRIPTION>
This edit targets the current collapse toward the mean by making the feature set more regime-invariant and more reactive to short-lived market structure changes, while also giving XGBoost a bit more capacity to use those signals.

Main ideas:
- Replace the current longer-horizon volatility regime logic with shorter rolling comparisons and rolling z-scores.
- Add autocorrelation and efficiency-trend features, which capture whether the market is becoming more or less trend-like.
- Keep feature count comfortably below 80.
- Increase model capacity modestly with more trees and slightly less restrictive splitting so the model can express a stronger slope on validation without exploding overfit.

Why this should help:
- The validation regime appears to differ from train/test, so shorter lookbacks and normalized signals should survive regime change better.
- The model is currently too flat on validation (`pred_std_ratio` is very low), so a little more tree capacity and weaker child-weight constraint should help restore prediction dispersion.
- The added trend-of-market-character features are designed to capture second-order regime shifts rather than just absolute levels.
</DESCRIPTION>
