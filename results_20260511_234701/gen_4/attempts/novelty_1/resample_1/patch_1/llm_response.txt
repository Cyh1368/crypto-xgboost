<DESCRIPTION>
This edit targets the regime-shift issue directly by making the model rely more on short-horizon, normalized, regime-invariant signals and by simplifying XGBoost so it prefers robust patterns over regime-specific memorization.

Key ideas:
- Reduce tree depth and add regularization to prevent overfitting to the training regime.
- Use shorter feature horizons (5-20 bars) and rolling z-scores so the same price/volume move is interpreted relative to recent local context.
- Add trend-of-regime features such as changes in volatility and efficiency, which should generalize better across the test→val shift.
- Add one multiplicative interaction between short momentum and volatility regime, as suggested, but in a normalized form.

The feature count stays comfortably below 80, and all features use only past data.
</DESCRIPTION>
