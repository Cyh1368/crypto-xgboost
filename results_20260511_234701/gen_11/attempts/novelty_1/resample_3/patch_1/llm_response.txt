4. **Lookback windows (60, 50, 200) are too long** for 15-min candles; they capture stale regime info

## Strategy

2. **Intra-window z-score normalization** — make features regime-invariant; a 2% move in high-vol regime is different from low-vol
3. **Remove slow vol_regime features** (rolling 200) that don't adapt quickly
4. **Increase model expressivity** — reduce min_child_weight, increase learning_rate slightly to capture regime-conditional patterns
5. **Add volatility-adaptive features** — scale momentum/returns by recent vol to make them robust across regimes

1. **Reducing lookback windows**: Replace 50/60/200 windows with 10/15/20 equivalents. 15-min candles move fast; long windows are stale.

2. **Z-score normalization within rolling windows**: For returns and deviations, compute (value - rolling_mean) / rolling_std to make features regime-invariant. A 1% return means different things in vol=0.5% vs vol=2% regimes.

3. **Volatility-adaptive scaling**: Multiply momentum features by vol_trend (fast/slow vol ratio) to capture regime-conditional behavior. In low-vol regimes, momentum is weaker; in high-vol, it's stronger.

4. **Remove slow regime features**: Drop 200-bar rolling windows and instead use faster 20-bar rolling ranks. This reduces stale information.

5. **Increase model expressivity**: Reduce min_child_weight from 1 to 0.5, increase learning_rate from 0.15 to 0.18, increase n_estimators to 500. This allows trees to pick up regime-conditional splits better.

6. **Simpler SMA cross**: Use SMA-10/20 instead of 10/50 for faster mean reversion detection.
