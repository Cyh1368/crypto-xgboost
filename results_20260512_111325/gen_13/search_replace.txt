<DESCRIPTION>
This edit targets the exact failure mode: the model’s slope collapses out-of-sample because it leans too much on absolute levels that shift across regimes. I’m making the feature set more regime-invariant by:
- replacing some long-horizon absolute features with shorter lookbacks,
- adding rolling z-score versions of key signals,
- adding rate-of-change features for volatility, efficiency, and autocorrelation,
- adding a momentum × volatility interaction on a short horizon.

I also reduce tree complexity and increase minimum child weight slightly so XGBoost is forced to prefer higher-support patterns that are less likely to evaporate in the validation regime. This should help raise val slope and pred_std_ratio without blowing up the train/val gap.
</DESCRIPTION>
