<DESCRIPTION>
This edit addresses the primary problem of slope collapse (0.074 train -> 0.006 val) by implementing regime-invariant features and more robust hyperparameters.

1.  **Hyperparameters:** Reduced `n_estimators` and `learning_rate`, and significantly increased `min_child_weight` (from 1 to 25) and `reg_lambda` (from 0 to 5.0). This forces the model to learn only the most robust patterns that appear in many samples, preventing overfitting to regime-specific noise.
2.  **Feature Engineering:**
    *   **Shorter Lookbacks:** Replaced long-term lags (up to 60+) with shorter, more responsive windows (1, 2, 4, 8, 16).
    *   **Z-Score Normalization:** Added rolling Z-scores for returns and volatility. This makes features regime-invariant (e.g., a 1% move is normalized by current volatility).
    *   **Rate of Change:** Added `vol_roc_5` to capture changes in market character.
    *   **Efficiency Ratio:** Added a shorter `efficiency_10` to detect trending vs. mean-reverting regimes faster.
    *   **Optimized OBI:** Replaced the slow `apply(axis=1)` with a faster column-wise `apply` for top-of-book imbalance.
    *   **Interaction Terms:** Refined momentum-volatility interactions to use normalized components.
3.  **Target Metrics:** Increased `MIN_PRED_STD_RATIO` to 0.18 to encourage more expressive predictions while maintaining robustness.
</DESCRIPTION>
