<DESCRIPTION>
This edit targets the main failure mode: the model has enough fit on train/test, but its predictive slope collapses in the most recent regime. I’m making the feature set more regime-invariant and more sensitive to changes in market character by:

- shifting several long lookbacks down to shorter horizons
- adding rolling z-scores for price/volatility/momentum so the model sees relative state, not raw level
- adding explicit “change in regime” features like volatility trend, efficiency trend, and autocorrelation trend
- adding a simple momentum × volatility interaction that often survives regime shifts better than either component alone
- slightly loosening the model regularization and reducing tree count so XGBoost can keep some expressivity without overfitting too hard

This should help recover val slope and pred_std_ratio while keeping the train→val gap controlled.
</DESCRIPTION>
