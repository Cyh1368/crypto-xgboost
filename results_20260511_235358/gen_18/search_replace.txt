This edit addresses the primary problem of slope collapse and prediction collapse by:
1. Increasing regularization (min_child_weight=25, reg_lambda=15.0) and reducing tree depth to force the model to learn broader, more robust patterns that generalize across regimes.
2. Introducing more regime-invariant features using local z-score normalization (mom_z_10, price_z_20, vol_z_60) and range-relative positioning (dist_range_20).
3. Adding short-term autocorrelation and volume z-scores to capture changes in market character (mean-reversion vs trending).
4. Adjusting the target clipping (97th percentile) and minimum prediction standard deviation ratio (0.18) to improve the model's signal-to-noise handling and expressivity.
