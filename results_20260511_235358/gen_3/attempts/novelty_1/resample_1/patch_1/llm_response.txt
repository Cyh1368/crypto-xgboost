# Analysis

The core problem is **regime instability**: the model learns patterns in training (slope=0.074) that collapse in validation (slope=0.006). The warnings confirm:
1. **Predictions collapse toward mean** → model lacks expressivity
2. **Features are regime-specific** → lookback windows are too long, features don't adapt to market regime shifts

The validation period appears to be a different market regime (different volatility, trend structure, or microstructure) than training/test.

## Root Causes

1. **Long lookback windows (60+ bars)** capture regime-specific patterns that don't transfer
2. **Absolute-level features** (e.g., `vol_20`, `trend_strength_60`) are non-stationary across regimes
3. **Low model capacity** (n_estimators=400, max_depth=5, min_child_weight=1) combined with high regularization can't learn robust patterns
4. **Missing regime-adaptive features** that explicitly measure how market character is changing

## Strategy

I'll implement three complementary changes:

1. **Shorter, regime-adaptive lookback windows** (5-15 bars for momentum, 20-30 for volatility) that decay faster
2. **Z-score normalization within rolling windows** to make features regime-invariant (a 1% move is contextualized by recent volatility)
3. **Rate-of-change features** (vol_trend, efficiency_trend) that measure how market character is shifting, not absolute levels
4. **Slightly increased model capacity** (n_estimators→500, min_child_weight→2) to learn more robust patterns without overfitting

    Build feature matrix from raw OHLCV + orderbook + funding data.
    All features must use only past data (no lookahead).
    Uses regime-adaptive features with Z-score normalization within rolling windows.

    feat = pd.DataFrame(index=df.index)

    close = df['close']
    volume = df['volume']
    high = df['high']
    low = df['low']

    # --- Returns (shorter lookbacks for faster adaptation) ---

    for w in [5, 10, 15, 20]:
        feat[f'vol_{w}'] = log_ret.rolling(w).std()

    # --- Volatility trend: how is volatility changing? (regime-adaptive) ---
    vol_5 = log_ret.rolling(5).std()
    vol_20 = log_ret.rolling(20).std()
    feat['vol_trend_5v20'] = (vol_5 - vol_20) / (vol_20 + 1e-9)  # is vol accelerating?
    feat['vol_accel'] = vol_5.diff(3)  # rate of change of volatility

    # --- RSI (shorter periods for faster adaptation) ---
    for period in [6, 12]:
        delta = close.diff()
        gain = delta.clip(lower=0).rolling(period).mean()
        loss = (-delta.clip(upper=0)).rolling(period).mean()
        rs = gain / (loss + 1e-9)
        feat[f'rsi_{period}'] = 100 - 100 / (1 + rs)

    # --- Bollinger Bands with Z-score normalization ---
    bb_mid = close.rolling(20).mean()
    bb_std = close.rolling(20).std()
    bb_pct = (close - bb_mid) / (2 * bb_std + 1e-9)
    feat['bb_pct'] = bb_pct
    # Z-score normalize bb_pct within rolling window (regime-invariant)
    feat['bb_pct_zscore'] = (bb_pct - bb_pct.rolling(15).mean()) / (bb_pct.rolling(15).std() + 1e-9)
