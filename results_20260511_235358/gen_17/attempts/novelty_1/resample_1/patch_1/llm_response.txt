**Current state:**
- val_slope=0.0031 (extremely low)
- pred_std_ratio=0.0441 (collapsed predictions)
- train_slope=0.0161 (even train slope is weak)
- The model is over-regularized and has lost predictive power entirely

**Root cause analysis:**
The current hyperparameters are TOO aggressive:
- min_child_weight=12 (forces very shallow splits, kills expressivity)
- reg_alpha=0.5, reg_lambda=5.0 (extreme regularization)
- subsample=0.7, colsample_bytree=0.7 (aggressive subsampling)
- learning_rate=0.06 (very slow learning)
- n_estimators=200 (too few to compensate)

This has crushed the model's ability to learn ANY signal. The train_slope itself is only 0.0161, which is 2-3x worse than prior attempts.

**Strategy:**
1. **Reduce regularization dramatically** - the model needs room to learn
2. **Increase model capacity** - more estimators, higher learning rate, less aggressive subsampling
3. **Loosen child weight constraint** - allow more granular splits
4. **Add regime-change detection features** - specifically measure volatility of volatility and momentum of momentum to catch regime shifts
5. **Improve feature normalization** - use adaptive z-scoring within shorter windows to make features regime-invariant

The key insight from prior attempts: the best score was -1.62 with val_slope=0.0078. We need to get back to that level of expressivity while adding better regime-detection features.
