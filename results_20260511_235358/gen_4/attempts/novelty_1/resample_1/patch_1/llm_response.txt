# Analysis

The core problem is clear: **regime shift between train and val periods**. The model learns from 60-bar volatility and long lookback features that don't generalize. The val_slope is 8.2% of train_slope — the model's ability to produce scaled predictions collapses.

Key observations:
1. **pred_std_ratio=0.112** — predictions are too compressed (need >0.18)
2. **val_slope=0.006** — predictions barely move (need >=0.020)
3. The gap between train→test (0.074→0.020) is smaller than test→val (0.020→0.006), suggesting val is a distinct regime
4. Long lookback windows (60 bars = 900 minutes) capture noise/regime-specific patterns

## Strategy

I will implement three targeted changes:

1. **Reduce lookback windows dramatically** — use 5-15 bar windows instead of 60-bar, which decay faster and capture more recent market dynamics
2. **Add z-score normalization within rolling windows** — makes features regime-invariant (a big move is big regardless of absolute volatility level)
3. **Add volatility-momentum trend features** — capture rate of change in market character rather than absolute levels
4. **Increase model expressivity** — reduce regularization and lower min_child_weight to allow the model to learn finer patterns in val regime
5. **Add a volatility regime scaling factor** — condition momentum features on current vol regime to make them adaptive
