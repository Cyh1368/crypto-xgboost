<DESCRIPTION>
The model currently suffers from a severe predictive slope collapse (0.074 train -> 0.006 val), indicating it relies on features that do not generalize across market regimes. 

This update implements three key strategies:
1. **Regime-Invariant Features**: Introduces rolling Z-scores for returns (Sharpe-like ratios) and Efficiency Ratios (Kaufman). These normalize market moves relative to recent volatility and noise, making them more consistent across high and low volatility environments.
2. **Shorter Lookbacks**: Shifts the focus from 60+ bar windows to 5-21 bar windows, as shorter-term patterns tend to decay slower and adapt faster to regime shifts.
3. **Enhanced Regularization**: Increases `min_child_weight` from 1 to 10 and adds L1/L2 regularization (`reg_alpha`, `reg_lambda`). This forces the XGBoost model to find patterns that are supported by larger sample sizes, reducing the likelihood of fitting noise in the training regime.
4. **Expressivity Tuning**: Lowers the learning rate and increases the number of estimators to allow the model to converge more gracefully on robust features.
</DESCRIPTION>

def build_features(df: pd.DataFrame) -> pd.DataFrame:
    """
    Build feature matrix from raw OHLCV + orderbook + funding data.
    All features must use only past data (no lookahead).
    Returns a DataFrame aligned to df.index.
    """
    feat = pd.DataFrame(index=df.index)

    close = df['close']
    volume = df['volume']
    high = df['high']
    low = df['low']

    # --- Returns ---
    for lag in [1, 2, 3, 6, 12, 24, 48]:
        feat[f'ret_{lag}'] = close.pct_change(lag)

    # --- Volatility ---
    log_ret = np.log(close / close.shift(1))
    for w in [5, 10, 20, 60]:
        feat[f'vol_{w}'] = log_ret.rolling(w).std()

    # --- RSI ---
    for period in [6, 14]:
        delta = close.diff()
        gain = delta.clip(lower=0).rolling(period).mean()
        loss = (-delta.clip(upper=0)).rolling(period).mean()
        rs = gain / (loss + 1e-9)
        feat[f'rsi_{period}'] = 100 - 100 / (1 + rs)

    # --- Bollinger Bands ---
    bb_mid = close.rolling(20).mean()
    bb_std = close.rolling(20).std()
    feat['bb_pct'] = (close - bb_mid) / (2 * bb_std + 1e-9)

    # --- ATR ---
    tr = pd.concat([
        high - low,
        (high - close.shift(1)).abs(),
        (low - close.shift(1)).abs()
    ], axis=1).max(axis=1)
    feat['atr_14'] = tr.rolling(14).mean()
    feat['atr_norm'] = feat['atr_14'] / close

    # --- MACD ---
    ema12 = close.ewm(span=12, adjust=False).mean()
    ema26 = close.ewm(span=26, adjust=False).mean()
    macd = ema12 - ema26
    feat['macd_signal'] = macd - macd.ewm(span=9, adjust=False).mean()

    # --- Volume ---
    feat['volume_ratio_5'] = volume / (volume.rolling(5).mean() + 1e-9)
    feat['volume_ratio_20'] = volume / (volume.rolling(20).mean() + 1e-9)
    vwap = (close * volume).rolling(20).sum() / (volume.rolling(20).sum() + 1e-9)
    feat['vwap_dev'] = (close - vwap) / (close + 1e-9)

    # --- Session / Time ---
    feat['hour_sin'] = np.sin(2 * np.pi * df.index.hour / 24)
    feat['hour_cos'] = np.cos(2 * np.pi * df.index.hour / 24)

    feat['efficiency_20'] = (close - close.shift(20)).abs() / (close.diff().abs().rolling(20).sum() + 1e-9)

    volume = df['volume']
    high = df['high']
    low = df['low']

    # --- Returns & Z-Returns (Sharpe-like) ---
    log_ret = np.log(close / close.shift(1))
    for lag in [1, 2, 3, 5, 8, 13, 21]:
        feat[f'ret_{lag}'] = close.pct_change(lag)
    for w in [5, 10, 20]:
        feat[f'ret_z_{w}'] = log_ret.rolling(w).mean() / (log_ret.rolling(w).std() + 1e-9)

    # --- Volatility & Vol-Z ---
    for w in [5, 10, 20]:
        feat[f'vol_{w}'] = log_ret.rolling(w).std()
    realized_vol_20 = log_ret.rolling(20).std()
    realized_vol_60 = log_ret.rolling(60).std()
    feat['vol_z_20'] = (realized_vol_20 - realized_vol_20.rolling(100).mean()) / (realized_vol_20.rolling(100).std() + 1e-9)

    # --- Efficiency & Regime ---
    for w in [10, 30]:
        feat[f'er_{w}'] = (close - close.shift(w)).abs() / (close.diff().abs().rolling(w).sum() + 1e-9)

    feat['vol_regime_fast'] = realized_vol_20 / (realized_vol_60 + 1e-9)
