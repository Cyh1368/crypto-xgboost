<DESCRIPTION>
This edit improves the signal generation and execution logic by incorporating several high-performance features from the best-performing seeds:
1.  **Elastic Thresholding**: Replaces the static volatility-adjusted threshold with an elastic multiplier that scales more dynamically with the volatility impulse (vol_5 / vol_20).
2.  **Refined Microstructure Weights**: Updates the weights for OBI and book pressure to the optimized values (0.32, 0.24, 0.24, 0.20).
3.  **Conviction-Based Sizing**: Introduces a continuous conviction ratio (predicted_return / threshold) to scale position sizes more granularly, replacing the binary conviction boost.
4.  **Volatility-Elastic Exits**: Adjusts take-profit and stop-loss levels based on both short-term volatility impulse and long-term volatility trends (vol_5 / vol_60).
5.  **Dynamic Time Horizon**: Reduces the max_bars from 4 to 3 when volatility is trending downwards, mitigating stagnation risk.
6.  **Relaxed Filters**: Slightly loosens the spread and funding filters to increase trade frequency while maintaining high quality.
