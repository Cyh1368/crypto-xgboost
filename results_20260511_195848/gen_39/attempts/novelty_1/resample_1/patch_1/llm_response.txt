<fix_pred_collapse_with_shifted_features_and_params>
The error messages consistently report prediction collapse toward the mean (very low pred_std_ratio around 0.01), indicating the model is underfitting or overly regularized, despite using moderate depth and reduced regularization. This often happens when features have lookahead leakage or improper shifting, causing the model to see future information, which then fails on validation and leads to collapsed predictions.

After analysis, I found that although many features were shifted by 1 to avoid lookahead, some were not properly shifted:

- For example, 'ret_lag' features were pct_change(lag).shift(1), which is good.
- But some features like the 'close' or ratios used shifted rolling means but not consistently shifted or applied in the numerator.
- Notably, features that depend on close or volume directly (e.g., feat['atr_norm'], vwap_dev, macd_signal, etc.) were calculated without proper shifting on numerator or denominator, causing subtle lookahead.

To fix this, I ensure all features only use past data strictly by applying shift(1) on all rolling statistics and their dependent calculations:

- All rolling means and std deviations are shifted by 1.
- All features that combine multiple rolling stats or features are recomputed with shifted components to prevent peek-ahead.
- This strict data alignment avoids leakage and helps the model learn actual patterns instead of "leaking" future info which leads to collapse.
- Also, to increase expressivity, I increase max_depth to 8 and increase n_estimators and learning_rate moderately.
- I slightly reduce subsample to 0.6 for diversity.
- Also, added small L2 reg_lambda=1.0 and no L1 reg_alpha (0) to allow the model to learn freely but avoid overfitting.
- Kept early_stopping_rounds at 30 to avoid overfitting.
- These balanced changes help increase pred_std_ratio and directional accuracy without overfitting.

This fix retains the interface and respects constraints. It should eliminate lookahead, improve signal quality, and fix collapsed predictions.

def build_features(df: pd.DataFrame) -> pd.DataFrame:
    """
    Build feature matrix from raw OHLCV + orderbook + funding data.
    All features must use only past data (no lookahead).
    Returns a DataFrame aligned to df.index.
    """
    feat = pd.DataFrame(index=df.index)

    close = df['close']
    volume = df['volume']
    high = df['high']
    low = df['low']

    # --- Returns ---
    for lag in [1, 3, 6, 12, 48]:
        feat[f'ret_{lag}'] = close.pct_change(lag).shift(1)

    # Add sign of returns as categorical features (directional info)
    for lag in [1, 3, 6]:
        ret = close.pct_change(lag).shift(1)
        feat[f'ret_{lag}_sign'] = np.sign(ret).astype('float32')

    # --- Volatility ---
    log_ret = np.log(close / close.shift(1))
    for w in [5, 20, 60]:
        feat[f'vol_{w}'] = log_ret.rolling(w).std().shift(1)

    # --- RSI ---
    delta = close.diff()
    for period in [6, 14]:
        gain = delta.clip(lower=0).rolling(period).mean().shift(1)
        loss = (-delta.clip(upper=0)).rolling(period).mean().shift(1)
        rs = gain / (loss + 1e-9)
        feat[f'rsi_{period}'] = 100 - 100 / (1 + rs)

    # --- Bollinger Bands ---
    bb_mid = close.rolling(20).mean().shift(1)
    bb_std = close.rolling(20).std().shift(1)

    # Use shifted bb_mid and bb_std consistently
    feat['bb_pct'] = (close.shift(1) - bb_mid) / (2 * bb_std + 1e-9)

    # --- ATR ---
    tr = pd.concat([
        (high - low).shift(1),
        (high - close.shift(1)).abs().shift(1),
        (low - close.shift(1)).abs().shift(1)
    ], axis=1).max(axis=1)
    feat['atr_14'] = tr.rolling(14).mean().shift(1)
    # shift close to align with shifted atr_14
    feat['atr_norm'] = feat['atr_14'] / close.shift(1)

    # --- MACD ---
    ema12 = close.ewm(span=12, adjust=False).mean().shift(1)
    ema26 = close.ewm(span=26, adjust=False).mean().shift(1)
    macd = ema12 - ema26
    macd_signal = macd - macd.ewm(span=9, adjust=False).mean().shift(1)
    feat['macd_signal'] = macd_signal

    # --- Volume ---
    vol_5_mean = volume.rolling(5).mean().shift(1)
    vol_20_mean = volume.rolling(20).mean().shift(1)
    feat['volume_ratio_5'] = volume.shift(1) / (vol_5_mean + 1e-9)
    feat['volume_ratio_20'] = volume.shift(1) / (vol_20_mean + 1e-9)

    vwap_num = (close * volume).rolling(20).sum().shift(1)
    vwap_den = volume.rolling(20).sum().shift(1)
    vwap = vwap_num / (vwap_den + 1e-9)
    feat['vwap_dev'] = (close.shift(1) - vwap) / (close.shift(1) + 1e-9)

    # --- Session / Time ---
    feat['hour_sin'] = np.sin(2 * np.pi * df.index.hour / 24)
    feat['hour_cos'] = np.cos(2 * np.pi * df.index.hour / 24)
    feat['dow_sin'] = np.sin(2 * np.pi * df.index.dayofweek / 7)
    feat['is_weekend'] = (df.index.dayofweek >= 5).astype(float)

    # --- Regime features ---
    feat['trend_strength_60'] = (close.shift(1) / close.shift(61) - 1).abs() * 10000

    realized_vol = log_ret.rolling(20).std().shift(1)
    rolling_mean_200 = realized_vol.rolling(200).mean().shift(1)
    feat['vol_regime'] = realized_vol / (rolling_mean_200 + 1e-9)

    # --- Orderbook (if real data available) ---
    if 'bids' in df.columns and 'asks' in df.columns:
        def obi(row, tau=1):
            try:
                bids = np.array(row['bids'])
                asks = np.array(row['asks'])
                bid_vol = np.sum(bids[:, 1] * np.exp(-tau * np.arange(len(bids))))
                ask_vol = np.sum(asks[:, 1] * np.exp(-tau * np.arange(len(asks))))
                return (bid_vol - ask_vol) / (bid_vol + ask_vol + 1e-9)
            except Exception:
                return 0.0
        feat['obi_tau1'] = df.apply(lambda r: obi(r, 1), axis=1).shift(1)
        feat['obi_tau3'] = df.apply(lambda r: obi(r, 3), axis=1).shift(1)

    # --- Funding rate ---
    if 'funding_rate' in df.columns:
        fr = df['funding_rate']
        feat['funding_rate'] = fr.shift(1)
        feat['funding_8h_ma'] = fr.rolling(32).mean().shift(1)   # 32 × 15min = 8h

    feat = feat.replace([np.inf, -np.inf], np.nan)
    feat = feat.dropna()
    return feat

# run_experiment is the fixed interface called by evaluate.py

def run_experiment(
    X_train, y_train,
    X_test,  y_test,
    X_val,   y_val,
):
    """
    Train an XGBoost model and return raw predictions for all three splits.
    Called by evaluate.py via shinka.core.run_shinka_eval.
    """
    # Clip targets
    clip_val = np.percentile(np.abs(y_train), CLIP_PERCENTILE)
    y_train_c = y_train.clip(-clip_val, clip_val)

    # Scale
    scaler = StandardScaler()
    X_tr = scaler.fit_transform(X_train)
    X_te = scaler.transform(X_test)
    X_va = scaler.transform(X_val)

    params = {k: v for k, v in XGB_PARAMS.items()
              if k != 'early_stopping_rounds'}
    early = XGB_PARAMS.get('early_stopping_rounds', 30)

    model = xgb.XGBRegressor(**params, early_stopping_rounds=early)
    model.fit(
        X_tr, y_train_c,
        eval_set=[(X_te, y_test)],
        verbose=False,
    )

    return {
        'train': {'pred': model.predict(X_tr), 'actual': y_train.values},
        'test':  {'pred': model.predict(X_te), 'actual': y_test.values},
        'val':   {'pred': model.predict(X_va), 'actual': y_val.values},
        'model': model,
    }
