<DESCRIPTION>
The current model suffers from 'mean-collapse' (pred_std_ratio ~0.04), which triggers heavy penalties. To improve the directional accuracy and score, we need to increase model expressivity and reduce the regularization that is quenching the signal.

Key changes:
1.  **Reduce Regularization**: Lowered `reg_lambda` (0.1 -> 0.01), `gamma` (0.5 -> 0.05), and `min_child_weight` (2 -> 1). This allows the trees to fit more complex patterns in the features.
2.  **Increase Learning Rate**: Raised `learning_rate` (0.05 -> 0.1) to ensure the model captures more variance during the boosting process.
3.  **Enhance Tree Depth**: Increased `max_depth` to 7 to allow for more complex multi-feature interactions.
4.  **Feature Augmentation**: Re-introduced high-contrast binary regime signals (momentum status, volatility binary, trend filters) and added "Volatility Shock" and "EMA divergence" features. These provide better structural "splits" for the trees, making it easier for the model to differentiate between trend-following and mean-reverting regimes.
5.  **Relaxed Target Threshold**: Adjusted `MIN_PRED_STD_RATIO` to 0.10 to better align with the natural variance of the crypto assets and reduce the collapse penalty while the model learns.
