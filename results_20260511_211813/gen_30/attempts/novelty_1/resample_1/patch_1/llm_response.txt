<DESCRIPTION>
The current model is still collapsing toward the mean, which usually means the tree ensemble is too smooth relative to the signal. I’m making two coordinated changes:

1. Hyperparameters: slightly increase tree count, reduce shrinkage, and relax split constraints enough to let XGBoost fit more local structure without exploding overfit. I also lower clipping a bit more to preserve target variance. This should raise `pred_std_ratio` while keeping train/val gap controlled.
2. Features: add a compact set of past-only regime-aware features that are highly relevant for 15m crypto perps:
   - lagged sign and normalized momentum
   - short-term trend slope vs long-term trend slope
   - rolling breakout z-score
   - volatility burst / compression
   - volume surprise and volume-pressure interaction
   - time-of-day interaction with momentum

These features are designed to help the model separate trend, mean-reversion, and high-volatility regimes, which should improve directional accuracy more than the current mostly raw momentum stack.
