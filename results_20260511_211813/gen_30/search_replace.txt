<DESCRIPTION>
The current model is still underfitting in the sense that predictions are too close to the mean, which is reflected in the low `pred_std_ratio` and the collapse penalty. I’m proposing two coordinated changes:

1. **Increase model expressivity while keeping regularization moderate**:
   - slightly deeper trees
   - more estimators with a lower learning rate
   - weaker `min_child_weight`, `reg_alpha`, and `reg_lambda`
   - a bit more randomness via subsampling
   This should help XGBoost fit the directional structure more strongly without making the overfit gap explode.

2. **Add regime-conditioned features and short-horizon signal features**:
   - shorter return horizons and return acceleration
   - realized-volatility percentile / z-score style regime indicators
   - trend-strength direction features
   - candle anatomy features
   - volume-price interaction features
   - a couple of funding/orderbook interaction terms
   - a lightweight interaction between momentum and regime
   These are designed to help the model separate trend, mean-reversion, and high-volatility states, which is often crucial for 15-minute perp futures.

The feature count remains comfortably under the 80-feature limit, and all features use only past data or contemporaneous bar data available at the close of the bar.
</DESCRIPTION>
