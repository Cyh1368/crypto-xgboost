<DESCRIPTION>
This update aims to fix the current “prediction collapse” symptom by making the tree ensemble a bit more expressive while keeping regularization moderate. The main issue in the latest results is that `pred_std_ratio` is still low, which means the model is too conservative and not separating bullish/bearish cases enough.

On the feature side, I’m adding a compact set of strictly past-only, lagged regime/momentum features. These are designed to help XGBoost learn when trend-following vs mean-reversion behavior is more likely, especially across changing volatility conditions. I also shift the orderbook/funding inputs by one bar to make the past-only constraint explicit and to reduce any chance of same-bar leakage.

The feature count remains comfortably below 80, and the added calculations are lightweight enough to stay within runtime limits.
</DESCRIPTION>
