<DESCRIPTION>
The current model is still showing a strong mean-collapse signal (`pred_std_ratio` well below the desired level), which usually means the trees are too constrained and the feature set is not giving enough short-horizon regime contrast.

This edit aims to improve expressivity in two complementary ways:

1. Loosen model regularization slightly and allow a bit more tree complexity:
   - increase depth from 5 to 6
   - reduce `min_child_weight`
   - reduce `reg_lambda`
   - reduce `learning_rate` a bit and compensate with more trees
   - keep early stopping, but give the model more room to learn structure

2. Add a compact set of high-signal features that are still strictly past-only:
   - short-horizon return acceleration
   - volatility-of-volatility
   - candle “location in range” over a short window
   - volume impulse / acceleration
   - ATR-normalized momentum and range expansion
   - a small regime interaction that should help in trend vs chop conditions

These additions are targeted to increase prediction spread without materially increasing feature count or risking leakage. The existing `keep_cols` stays under 80, and the new features are selected to be information-dense rather than redundant.
</DESCRIPTION>
