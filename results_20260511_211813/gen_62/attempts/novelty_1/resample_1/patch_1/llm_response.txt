<DESCRIPTION>
The current model still shows low prediction spread, which is consistent with under-expressive trees and features that are too smooth for 15-minute crypto perp directionality. This edit makes the booster a bit more expressive while keeping regularization moderate, and replaces some slower, redundant long-memory inputs with stronger short-horizon regime-aware signals.

Key ideas:
- slightly deeper trees, more estimators, lower learning rate for richer fits without overfitting too hard
- reduce clipping a bit to preserve tail signal
- add short-horizon momentum acceleration, rolling return dispersion, price location within rolling range, and a simple trend-vs-volatility interaction
- keep strict past-only usage by shifting all rolling statistics
- stay well below the 80-feature limit

This should help move pred_std_ratio upward without blowing out the overfit gap, and improve directional sensitivity on unseen validation bars.
</DESCRIPTION>
