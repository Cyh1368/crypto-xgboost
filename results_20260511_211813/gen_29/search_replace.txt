<DESCRIPTION>
The current model is still too conservative: pred_std_ratio is very low, which means the booster is collapsing toward the mean. To improve directional accuracy, I’m making two targeted changes:

1. Hyperparameters: increase tree capacity a bit, reduce regularization, and add column/bagging randomness so XGBoost can fit more directional structure without becoming unstable. This should raise prediction dispersion while keeping overfit controlled by using moderately deep trees and a slightly lower learning rate.

2. Features: add regime-aware and normalized momentum features that are still causal and cheap to compute:
   - short-horizon return z-scores to detect local bursts vs. drift,
   - multi-window momentum direction features,
   - trend strength and volatility regime from shorter windows,
   - wick/body imbalance to capture candle structure,
   - rolling correlation between returns and volume change as a simple flow proxy.

These features are designed to help the model separate trending from mean-reverting periods, which is often critical for perp futures DA. The total feature count remains comfortably below the limit.
