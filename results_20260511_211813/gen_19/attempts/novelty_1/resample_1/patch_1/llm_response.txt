<DESCRIPTION>
This edit aims to address the main remaining failure mode: prediction collapse toward the mean. The current model already has decent DA, but `pred_std_ratio` is still too low, which usually means the tree ensemble is not seeing enough separable structure after scaling and regularization.

I’m proposing two complementary changes:

1. **Loosen the XGBoost regularization slightly and increase model capacity carefully**
   - Lower `min_child_weight` and `gamma` so trees can split on smaller but useful micro-signals.
   - Reduce `reg_lambda` a bit and increase `n_estimators` modestly with a slightly lower learning rate, which often improves out-of-sample DA while avoiding a sharp overfit jump.
   - This should help increase prediction dispersion without making the model unstable.

2. **Add a small set of strictly past-only regime and shape features**
   - Use `shift(1)` before rolling statistics so the features are explicitly lagged.
   - Add short-horizon return dispersion, skew-ish candle structure, rolling slope, and volume surprise features.
   - Add a couple of regime-conditioned interactions that are useful in 15-minute crypto perp data, especially when momentum and volatility regimes differ.
   - Keep feature count well below 80.

Overall, the goal is to increase expressivity enough to lift `pred_std_ratio` above the collapse zone while preserving the current ~0.53 DA level or better.
