# Analysis

Looking at the performance trajectory, the model has consistently achieved **val_DA ≈ 0.53** across multiple iterations, but the **collapse penalty remains high (0.45–0.60)** due to `pred_std_ratio ≈ 0.05–0.06`. This indicates the model is still predicting too close to the mean despite aggressive regularization reduction.

## Key Observations

1. **Persistent collapse**: Even with `reg_lambda=0.02`, `reg_alpha=0.001`, and `max_depth=6`, predictions lack variance.
2. **Regularization paradox**: Lowering regularization hasn't solved the problem—the issue is likely **feature signal quality**, not hyperparameters.
3. **Feature bloat**: The current feature set (60+ features) includes many redundant interaction terms that may be diluting signal.
4. **Regime conditioning underutilized**: Binary regime features exist but aren't being leveraged effectively.

## Proposed Solution

**Aggressive feature pruning + targeted signal amplification:**
- Remove redundant/noisy interaction features that add complexity without signal
- Keep only the highest-quality momentum, volatility, and regime indicators
- Add **explicit volatility-scaled prediction targets** to encourage the model to predict larger moves in high-vol regimes
- Increase learning rate and reduce early stopping patience to allow more aggressive fitting
- Reduce `max_depth` to 5 to force cleaner splits on high-signal features

This approach:
1. **Reduces feature noise** → clearer gradient signal
2. **Focuses the model** on strongest predictors
3. **Increases model expressivity** through higher learning rate and deeper trees (relatively)
4. **Targets the collapse directly** by removing features that push predictions toward mean
