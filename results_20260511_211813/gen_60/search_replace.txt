<DESCRIPTION>
The current model is still collapsing toward the mean, which suggests the feature set is not giving XGBoost enough sharp, regime-dependent splits. I’m proposing a targeted upgrade that does two things:

1. **Increase expressivity slightly in the booster**
   - Reduce `reg_lambda` and `gamma` a bit, keep `min_child_weight` low, and add a modest increase in trees.
   - This should help the model use the already-strong features more aggressively without blowing up overfit too much.

2. **Add a compact set of higher-signal regime/momentum features**
   - Focus on normalized momentum, short-term trend slope, volatility compression, rolling skew, and a few interactions that XGBoost can split on cleanly.
   - These are past-only features and should help distinguish when momentum should be trusted vs faded.
   - Keep feature count well below the 80-feature limit.

3. **Reduce target clipping slightly less aggressively**
   - The current 95th percentile clip may be suppressing useful directional signal.
   - Moving back to a more moderate clip should improve prediction variance and reduce collapse penalty.

Overall, this aims to raise `pred_std_ratio` while preserving or improving validation DA.
