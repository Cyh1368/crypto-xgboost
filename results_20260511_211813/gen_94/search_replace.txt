<DESCRIPTION>
The current model is heavily underconfident (`pred_std_ratio` is far below target), which usually means the tree ensemble is too constrained and the feature set is not providing enough separable regime information. I’m proposing two coordinated changes:

1. Relax XGBoost regularization and give it more capacity to fit weak but real directional edges:
   - more trees,
   - slightly deeper trees,
   - lower `min_child_weight`,
   - lower `reg_lambda`,
   - a bit more subsampling to retain robustness,
   - slightly smaller learning rate with more rounds.

2. Add a small set of high-value past-only features that improve regime discrimination without exploding dimensionality:
   - normalized lagged returns and return spreads,
   - short-horizon realized volatility shifts,
   - EMA-based trend spread,
   - VWAP-distance z-score,
   - RSI slope / midline state,
   - volume shock / price-volume interaction,
   - a short regime persistence measure.

These features are designed to help the model separate trend, mean-reversion, and volatility-expansion periods, which should improve directional accuracy while also increasing prediction dispersion away from the mean.
</DESCRIPTION>
