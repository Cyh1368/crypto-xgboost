<DESCRIPTION>
The current model is still predicting too close to the mean, which is consistent with overly conservative tree growth and a feature set that is useful but not diverse enough to separate bullish vs bearish 15-minute regimes.

This edit makes two coordinated changes:

1. Loosens the XGBoost regularization and increases model capacity slightly:
   - more trees, slightly deeper trees
   - lower `min_child_weight`, `reg_alpha`, `reg_lambda`
   - lower learning rate to stabilize the extra capacity
   - slightly more aggressive clipping (`CLIP_PERCENTILE=99`) so the model can see a wider target range

2. Expands `build_features()` with short-horizon regime-sensitive signals that are still causal:
   - fast/medium return momentum
   - return spread and acceleration
   - rolling z-score of returns
   - volume z-score and volume change
   - range expansion and candle body/wick structure
   - price position inside recent high/low range
   - trend vs mean-reversion interaction using short-vs-long momentum
   - a volatility-adjusted momentum feature

These additions are designed to improve directional separation without blowing up feature count or introducing lookahead. The feature total remains comfortably below 80.
</DESCRIPTION>
