<DESCRIPTION>
This edit introduces a more sophisticated feature set and hyperparameter configuration, drawing from the most successful prior experiments. 

Key changes:
1.  **Hyperparameters:** Adjusted `max_depth` to 5 and `min_child_weight` to 5 to balance expressivity and generalization. Increased `learning_rate` to 0.03 and `n_estimators` to 850 to improve model confidence and escape the "collapse toward mean" failure mode.
2.  **Multi-scale Returns:** Added returns and acceleration across multiple time horizons (1, 3, 6, 12, 24, 48 bars) to capture both micro-trends and structural shifts.
3.  **Volatility Regimes:** Implemented volatility ratios (e.g., 8-period vs 96-period) and a "volatility state" indicator using a tanh transformation to help the model distinguish between trending and mean-reverting environments.
4.  **Rolling Quantiles:** Added rolling rank-based features for returns and volume. These are more robust to non-stationary financial data than raw values or z-scores.
5.  **Structural Indicators:** Included EMA gaps (distance between fast, mid, and slow averages) and VWAP deviations normalized by ATR to capture mean-reversion pressure.
6.  **Microstructure:** Refined candle geometry features (body size, wick lengths, and close location within the bar) to capture intra-bar sentiment.
7.  **Interactions:** Added targeted interaction terms like `trend_x_vol` and `breakout_pressure` to condition momentum signals on the current market regime.
