<DESCRIPTION>
The current model is still under-dispersed (`pred_std_ratio=0.11`) and the validation edge is only slightly above chance. The safest way to improve both directional signal and output variance is to make the booster a bit more expressive while adding a few high-value, strictly past-looking features that capture short-horizon momentum, trend persistence, and regime shifts.

I’m proposing:
1. Loosen the XGBoost regularization slightly and lower the learning rate with more estimators so the model can fit richer nonlinear structure without becoming too brittle.
2. Add a compact set of lagged / regime-aware features built from shifted series only:
   - short-horizon return stack on past closes
   - return trend and return acceleration
   - rolling slope proxy for trend persistence
   - breakout position and range expansion
   - volume surprise and volume trend
   - volatility compression / expansion
   - optional orderbook imbalance change and funding momentum, shifted to remain past-only

These features are aimed at reducing mean-prediction collapse while preserving generalization. The feature count stays comfortably under the limit, and the changes are small enough to keep runtime practical.
