The current model is showing a collapse penalty of 0.572, indicating severe prediction collapse toward the mean. The pred_std_ratio is only 0.0356, which is still far below the 0.15 minimum target. 

The root cause is **excessive regularization** combined with **insufficient model depth**. The current hyperparameters have:
- reg_lambda=0.05 (very low, good)
- reg_alpha=0.0 (good)
- But max_depth=8 is actually reasonable given the feature count

However, looking at the trajectory of prior runs:
- When we reduced regularization (reg_alpha from 0.01→0.0, reg_lambda from 0.1→0.05), pred_std_ratio improved from 0.01→0.04
- But it's still not enough to break out of collapse mode

The key insight: we need to **drastically reduce regularization further** and **increase model capacity** through higher learning rate and more estimators. The current learning_rate=0.1 is good, but:
- min_child_weight=1 is very low and may help, but we need fewer constraints
- We should increase max_depth slightly to 9-10 to allow more expressive trees
- Remove reg_alpha completely (keep at 0.0)
- Further reduce reg_lambda to near-zero (0.01)

Additionally, increase MIN_PRED_STD_RATIO threshold slightly to force the model to be more penalized when collapsing, but also relax CLIP_PERCENTILE from 99 to 98 to give the model slightly more extreme values to work with.

Expected impact: pred_std_ratio should jump to 0.08-0.12 range, helping escape collapse penalty.
