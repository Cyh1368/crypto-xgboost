<DESCRIPTION>
The current model is still collapsing toward the mean, which usually means the tree ensemble is too constrained relative to the signal in 15-minute perp returns. I’m proposing two coordinated changes:

1. Loosen XGBoost regularization and increase tree budget slightly so the model can express sharper directional edges without over-smoothing.
   - Reduce `min_child_weight`, `reg_alpha`, and `reg_lambda`
   - Use a slightly higher learning rate with more trees
   - Add `gamma=0` explicitly to avoid unnecessary split suppression

2. Expand the feature set with a compact regime-aware stack:
   - Short/medium EMA gaps and slope features
   - ATR-normalized impulse / trend efficiency
   - A simple ADX-like directional strength proxy
   - Longer range-position context
   - A few cross-regime interactions that help the model behave differently in trend vs chop

This should help increase `pred_std_ratio` while keeping feature count comfortably below the limit and avoiding any lookahead.
