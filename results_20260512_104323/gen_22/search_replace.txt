<DESCRIPTION>
The primary goal is to address the model's collapse in predictive slope and regression in performance from test to validation periods. This indicates the model is overfitting to specific market regimes (volatility levels, trendiness) present in the training data that do not persist.

Key changes:
1.  **Local Z-Score Normalization**: All core features (returns, volume, RSI, MACD) are now normalized using rolling Z-scores (using a 50-bar window). This makes features regime-invariant; for example, a return of 0.5% is interpreted relative to recent volatility rather than as an absolute value.
2.  **Market Character Change Features**: Added "Efficiency Ratio" (Kaufman), "Volatility Trend", and "Autocorrelation" to explicitly measure whether the market is currently trending, mean-reverting, or shifting between these states.
3.  **Interaction Terms**: Simplified interactions to `momentum / volatility` and `momentum * efficiency` to capture how price action behaves in different regimes.
4.  **XGBoost Regularization**: Switched to a shallower `max_depth` (3) and significantly higher `min_child_weight` (25). This forces the model to find patterns that are supported by a large number of samples, improving generalization across the regime shift observed between the test and validation sets.
5.  **Target Clipping**: Increased `CLIP_PERCENTILE` to 98 to allow the model to see slightly more of the tail distribution, which helps prevent slope collapse.
</DESCRIPTION>

def build_features(df: pd.DataFrame) -> pd.DataFrame:
    """
    Build highly robust, regime-invariant features using rolling z-scores
    and market efficiency indicators.
    """
    feat = pd.DataFrame(index=df.index)

    close = df['close']
    volume = df['volume']
    high = df['high']
    low = df['low']
    open_ = df['open']
    log_ret = np.log(close / close.shift(1))

    # Helper for rolling z-scores
    def rolling_z(series, w_lookback, w_stats=50):
        m = series.rolling(w_stats).mean()
        s = series.rolling(w_stats).std()
        return (series - m) / (s + 1e-9)

    # --- Returns & Momentum (Local Z-Score) ---
    for w in [1, 3, 6, 12]:
        r = close.pct_change(w)
        feat[f'ret_z_{w}'] = rolling_z(r, w, 60)

    # --- Volatility Dynamics (Local Z-Score) ---
    for w in [5, 15, 30]:
        v = log_ret.rolling(w).std()
        feat[f'vol_z_{w}'] = rolling_z(v, w, 100)

    # --- Rate of character change ---
    vol_fast = log_ret.rolling(5).std()
    vol_slow = log_ret.rolling(20).std()
    feat['vol_regime_ratio'] = vol_fast / (vol_slow + 1e-9)
    feat['vol_trend'] = vol_fast.diff(5) / (vol_slow + 1e-9)

    # Kaufman's Efficiency Ratio (ER) - measure of noise vs trend
    def get_er(series, w):
        direction = (series - series.shift(w)).abs()
        volatility = series.diff().abs().rolling(w).sum()
        return direction / (volatility + 1e-9)

    feat['er_10'] = get_er(close, 10)
    feat['er_trend'] = feat['er_10'].diff(5)

    # --- Normalized Oscillators ---
    for w in [7, 14]:
        delta = close.diff()
        gain = delta.clip(lower=0).rolling(w).mean()
        loss = (-delta.clip(upper=0)).rolling(w).mean()
        rsi = 100 - 100 / (1 + (gain / (loss + 1e-9)))
        feat[f'rsi_z_{w}'] = rolling_z(rsi, w, 60)

    # --- Price position and mean reversion ---
    bb_mid = close.rolling(20).mean()
    bb_std = close.rolling(20).std()
    feat['bb_pct'] = (close - bb_mid) / (2 * bb_std + 1e-9)
    feat['vwap_dev_z'] = rolling_z((close - (close * volume).rolling(15).sum() / (volume.rolling(15).sum() + 1e-9)), 15, 60)

    # --- Force Robust Interactions ---
    feat['mom_vol_adj'] = close.pct_change(5) / (vol_slow + 1e-9)
    feat['mom_er_adj'] = close.pct_change(5) * feat['er_10']

    # --- Volume Dynamics ---
    vol_ma = volume.rolling(20).mean()
    feat['vol_surge_z'] = rolling_z(volume / (vol_ma + 1e-9), 20, 60)
    feat['vol_ret_corr'] = log_ret.rolling(15).corr(volume.pct_change(1))

    # --- Candlestick Character ---
    tr = pd.concat([high - low, (high - close.shift(1)).abs(), (low - close.shift(1)).abs()], axis=1).max(axis=1)

    feat['candle_body_ratio'] = (close - open_).abs() / ((high - low) + 1e-9)
