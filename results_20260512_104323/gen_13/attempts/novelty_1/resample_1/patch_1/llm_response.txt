<DESCRIPTION>
This edit aims to solve the slope collapse by making the feature set more regime-invariant and more responsive to recent market structure. It does three things:

1. **Shortens the effective lookback horizon** for core momentum/volatility signals so they decay faster and are less tied to stale training regimes.
2. **Adds rolling z-score normalization and trend-of-regime features** for volatility, autocorrelation, and efficiency ratio, which helps the model compare “recent” behavior relative to the local past instead of using absolute levels.
3. **Relaxes model regularization slightly** and increases tree count a bit so XGBoost can recover predictive slope without collapsing predictions toward the mean.

The feature count remains well under the 80-feature limit, and all features use only past data.
</DESCRIPTION>
