<DESCRIPTION>
This edit targets the main failure mode: the model’s slope collapses in the newest regime, which usually means it is learning absolute levels that do not survive regime shifts. The proposed feature set emphasizes short-horizon, regime-invariant signals:

- shorter lookbacks for returns, volatility, trend strength, and mean-reversion
- rolling z-scored versions of return, volatility, RSI, and price deviation
- explicit rate-of-change features for volatility and efficiency
- short-window autocorrelation and its trend, which helps capture market character changes
- a stronger momentum × volatility-regime interaction using normalized momentum

I also slightly relax the tree regularization so XGBoost can fit these more informative but noisier short-term signals without collapsing toward the mean. This should help raise val_slope and pred_std_ratio while keeping overfit under control.
</DESCRIPTION>
