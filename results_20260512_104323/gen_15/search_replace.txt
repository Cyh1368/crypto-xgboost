<DESCRIPTION>
The model currently suffers from prediction collapse (very low slope and pred_std_ratio) and poor generalization across regimes.

Key changes:
1.  **Increased Model Expressivity**: Boosted `max_depth` to 5, decreased `min_child_weight` to 2, and reduced `reg_lambda` to 0.6. This allows the model to capture more complex patterns and prevents it from collapsing toward the mean.
2.  **Vol-Normalized Returns**: Replaced raw returns with volatility-normalized returns (`ret / (vol * sqrt(lag))`). This makes return features regime-invariant, as a 1% move is scaled by the current market volatility.
3.  **Regime-Invariant Volatility**: Replaced raw volatility with Z-scored volatility and added a rolling `vol_rank_100`. Rank-based features are perfectly regime-invariant.
4.  **Removed Slow Operations**: Removed the `ret_autocorr_5` feature which uses a slow `.apply()` call, improving execution speed.
5.  **Added Robust Indicators**: Added a 14-period Stochastic %K (`stoch_k_14`) which is naturally bounded and robust to price scaling.
6.  **Adjusted Learning Rate**: Increased `n_estimators` to 400 and tuned the `learning_rate` to 0.06 to allow for better convergence with the increased depth.
</DESCRIPTION>
